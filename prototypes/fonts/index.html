Font pairings for the slim hero

Six candidates, numbered 1 to 6, plus the two pairings already tried (R1, R2). Every row is the same Round 6 hero markup; only the font custom properties in fonts.css change. Dark ground left, light ground right.

All eight are SIL OFL 1.1 and variable. Fontshare faces were left out on purpose: their license (ITF FFL v2) forbids subsetting and format conversion, and bars serving fonts to third parties who customize content, which sits badly with Remix and a public repo.

  • 1. Martian Grotesk (top pick)
  • 2. Mona Sans Expanded
  • 3. Geologica
  • 4. Commissioner
  • 5. Literata Display
  • 6. Recursive
  • R1. Archivo condensed
  • R2. Bricolage Grotesque
01

1. Martian Grotesk + Martian MonoTop pick

Grotesk with quirks, parametric. One parametric system (width 75 to 200, weight 100 to 1000) with brutalist quirks: overhanging a/e/s terminals and mono-style hooks on f, j, t. A system you can see the knobs of, with a face of its own. Its mono sibling shares the DNA, so labels never feel bolted on.

Display
Martian Grotesk 780, width 100%. Evil Martians (Roman Shamin)
Text
Martian Grotesk 400. Same file
Label
Martian Mono 400, width 87.5%. Evil Martians
Variable axes
Grotesk: wdth 75 to 200, wght 100 to 1000. Mono: wdth 75 to 112.5, wght 100 to 800
License
SIL OFL 1.1. Free for commercial use, self-host, subset and convert freely; keep the license with the files. Grotesk is self-hosted from GitHub (v1.0.0, 116 KB woff2); Mono is on Google Fonts. Round 5 already uses Martian Mono for labels.

02

2. Mona Sans Expanded + Mona Sans

Wide / extended. The closest free cousin of the Aktiv Grotesk text Jarod liked on aarronwalter.com, plus a real width axis. The name sets wide and heavy, the bio sets at normal width: one family, two personalities, and Remix gets width as a lever. Labels are its own caps, no mono.

Display
Mona Sans 860, width 125%. GitHub with Degarism Studio
Text
Mona Sans 400, width 100%
Label
Mona Sans 600, width 112.5%, caps
Variable axes
wdth 75 to 125, wght 200 to 900 (italic available)
License
SIL OFL 1.1. Free for commercial use, self-host, subset and convert freely; keep the license with the files. Google Fonts. Trade-off: it is GitHub's brand face, so some engineers will recognize it.

03

3. Geologica + Spline Sans Mono

Geometric, with a sharpness dial. A clean geometric grotesk with a Sharpness axis that cuts the joins into ink-trap notches. Sharp at display size, soft at 16px: the engineering detail only shows where it can be seen. SHRP becomes a Remix token.

Display
Geologica 720, SHRP 100. Monokrom (Sindre Bremnes, Frode Helland)
Text
Geologica 350, SHRP 0
Label
Spline Sans Mono 450. Eben Sorkin, Mirko Velimirovic
Variable axes
Geologica: wght 100 to 900, SHRP 0 to 100, CRSV 0 to 1, slnt -12 to 0. Spline Sans Mono: wght 300 to 700
License
SIL OFL 1.1. Free for commercial use, self-host, subset and convert freely; keep the license with the files. Both on Google Fonts.

4. Commissioner (flared) + Commissioner

Humanist, flared. A warm humanist sans whose Flair axis grows chiseled, flared terminals for the name, then flattens to a calm low-contrast text face for the bio. Craft and warmth without leaving the system. No mono anywhere: labels are tracked caps.

Display
Commissioner 680, FLAR 100, VOLM 70. Kostas Bartsokas
Text
Commissioner 400, FLAR 0
Label
Commissioner 600, caps, tracked
Variable axes
wght 100 to 900, FLAR 0 to 100, VOLM 0 to 100, slnt -12 to 0
License
SIL OFL 1.1. Free for commercial use, self-host, subset and convert freely; keep the license with the files. Google Fonts.

5. Literata Display + Hanken Grotesk + Fragment Mono

Serif-led. An editorial lead: Literata at its 72pt optical size is crisp and contemporary, not bookish. The bio drops into a plain, sturdy grotesk; Fragment Mono (Helvetica-flavored mono) keeps the labels Swiss. Reads as a writer who builds systems.

Display
Literata 560, opsz 72. TypeTogether
Text
Hanken Grotesk 400. Hanken Design Co.
Label
Fragment Mono 400. Wei Huang, URW
Variable axes
Literata: opsz 7 to 72, wght 200 to 900. Hanken: wght 100 to 900. Fragment Mono: static
License
SIL OFL 1.1. Free for commercial use, self-host, subset and convert freely; keep the license with the files. All on Google Fonts.

6. Recursive (Casual / Linear / Mono)

Technical, one file. One variable file plays all three roles: Casual for the name, Linear for the bio, MONO=1 for labels. The personality is literally an axis (CASL 0 to 1), so Remix can dial the whole site from engineer to human. Riskiest: Casual can read playful.

Display
Recursive 820, CASL 1. Arrow Type (Stephen Nixon)
Text
Recursive 400, CASL 0, MONO 0
Label
Recursive 450, MONO 1
Variable axes
wght 300 to 1000, CASL 0 to 1, MONO 0 to 1, CRSV 0 to 1, slnt -15 to 0
License
SIL OFL 1.1. Free for commercial use, self-host, subset and convert freely; keep the license with the files. Google Fonts. Smallest payload of the six: one file covers every role.

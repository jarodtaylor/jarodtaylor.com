Building blocks: three layouts

Same HTML as the live site (seeded from pnpm build, in seed/). Each option adds one override sheet written as knobs; its header comment lists the knobs it would need.

  1. 1. MonumentOne centre line: the JT stands on a giant name like a block on a plinth, tagline and bio flank it, the info strip is the baseplate. Nav centred; links snap up into paper blocks.
  2. 2. BaseplateThe hero is built from tiles: name on a persimmon slab, JT in a deep-cobalt bay, bio on paper, links as four bricks. Nav is a tray of bricks that lift on hover.
  3. 3. SpineThe header becomes a left rail with the info strip as a vertical spine; JT on the left page, name stacked on the right. Nav is always a full-height drawer whose links fall in and stack.

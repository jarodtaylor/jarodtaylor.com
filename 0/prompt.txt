DECISIONS
- tokens-fresh compares file contents before and after `pnpm tokens` instead of asking git. That works with no commits or untracked files, and in CI it means the same as "the committed output matches its source".
- contrast pairs come from the naming: every sibling of `surface.<role>.bg` is text at 4.5:1. `border` is skipped as decorative (no component relies on a border to be identified). `focus` is 3:1. No large-text roles yet; there's a LARGE_TEXT set ready for when one is designated. A role with a bg but no text fails, and so do foregrounds with no bg.
- tokens-only:
  - Allowed var() names come from the semantic and component source files in resolver.json, so no build is needed and typos are caught.
  - Primitives get their own error message.
  - Component CSS may only declare `--_` props.
  - Raw units are banned except % and fr. Unitless 0 is fine. Durations are banned (motion is a token).
  - color-mix and light-dark are banned because they escape check:contrast.
  - font, font-family, font-size, font-weight, line-height and letter-spacing must each be a single var() (font-weight, line-height and letter-spacing go beyond what you asked for).
  - The brand rule keys on `data-brand` / `--brand`, never on brand names: "alt" and "default" would collide with `[alt]` and `--surface-default-*`.
  - Not linted: generated tokens.css and reset.css.
  - Zero global allowlist. The one exception is two `stylelint-disable-next-line … -- reason` comments for the 1px visually-hidden idiom in utilities.css. A disable with no reason fails the lint.
- markup-invariance runs each page × each brand as the starting brand (loaded via ?brand=), switches to every other brand, and snapshots body.outerHTML with one tag per line. The Remix hook removes state attributes (open/hidden/inert/aria-expanded/pressed/checked/data-state) on `[data-remix-ui]` and its descendants. Excluding only those attributes, not whole subtrees, keeps the exclusion narrow.
- a11y uses tags wcag2a/2aa/21a/21aa/22aa, fails on serious or critical, and prints moderate and minor without failing.
- Lighthouse: `pnpm lighthouse` runs collect + assert only, because `lhci autorun` would publish to public storage from a laptop. CI runs collect, then upload (temporary-public-storage, always), then assert, and uploads .lighthouseci/ as an artifact. A PR labelled `perf-tradeoff` turns the assert step into continue-on-error. That's my reading of the plan's "labeled override".
- e2e files are named *.e2e.ts so Vitest's default *.spec.ts pattern doesn't pick them up.

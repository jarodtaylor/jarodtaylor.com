**What Figma's docs say (help.figma.com, "Modes for variables"):**

  - duration: seconds only

  - string: accepted

**Minimal schema changes:**
1. Put `$type` on every token.
2. Dimensions become px. derive() converts to rem as base/16.
3. Durations become seconds.
4. Weights become `number`; derive emits fontWeight.
5. Easings become strings like `"0.16, 1, 0.3, 1"`, parsed by derive.
6. fontFamily becomes a single name. derive appends `"<name> Fallback"` (the metric-matched face, A5) plus a generic family. The generic comes from a new string enum knob per role: sans-serif | serif | monospace.

8. Fluid, variation, tracking and enums stay strings. Enum lists live only in derive.ts, so I drop the `$extensions` agreement check.
9. Descriptions move into derive.ts.

**Excluded from Figma:** only generated primitives.

**First step:** a round-trip spike through import, export, `pnpm tokens` and a diff.
